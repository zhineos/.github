# Zhineos

Physics calculations, both numerical and analytical, revisited and collected in one place.

I created this organization to bring together the physics work I have taken
up again from my earlier research: cosmology (from my undergraduate studies,
before I started my master's in 2006), condensed matter (from 2010), and
particle physics (from 2016). For now it is a single place to keep these
projects as I return to them, clean them up, and extend them.

## What you'll find here

- Numerical calculations and simulations: the code behind each result,
  with instructions for running it.
- Analytical calculations: full derivations, typeset in LaTeX next to the
  code that checks them numerically.
- Manuscripts and preprints: the write-ups that come out of this work.

Each project has its own repository, and its README explains what the
project contains and how to reproduce its results.
